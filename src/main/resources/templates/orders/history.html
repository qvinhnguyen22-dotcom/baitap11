💡 Hướng dẫn kiểm thử lọc trạng thái (Yêu cầu đề bài): Đề bài yêu cầu: "vào database để thay đổi các trạng thái để quan sát trạng thái đơn thay đổi theo trạng thái tương ứng".
Bạn có thể mở SQL Server và chạy lệnh: UPDATE orders SET status = N'Đã xác nhận' WHERE id = 1; (hoặc Chuẩn bị hàng, Vận chuyển, Giao hàng, Đã giao, Đơn hàng hủy, Đơn hàng hoàn). Sau khi cập nhật DB, hãy tải lại trang này hoặc nhấn vào tab tương ứng để quan sát đơn hàng hiển thị chính xác theo trạng thái đã đổi!
